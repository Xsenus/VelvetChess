# Чек-лист публикации в RuStore

- [ ] Выполнить `scripts/Set-ReleaseOwnerData.ps1` с реальными публичными данными владельца.
- [ ] Зарегистрировать уникальное название и подтвердить package ID `ru.velvetchess.game`.
- [ ] Создать и безопасно сохранить release keystore; не добавлять его и пароли в Git.
- [x] Собрать и проверить QA APK/AAB с debug-подписью.
- [x] Проверить package ID, версии SDK и отсутствие чувствительных разрешений.
- [ ] Собрать подписанный AAB или APK командой из `docs/RELEASE.md`.
- [ ] Выполнить `scripts/Test-RuStoreReadiness.ps1` без `AllowOwnerPlaceholders` и устранить все ошибки.
- [ ] Проверить установку release-сборки на реальном Android-устройстве.
- [ ] Пройти все сценарии из `docs/QA.md`.
- [x] Снять фактические экраны Android-приложения на эмуляторе API 35 в формате 1080×1920 автоматизированным smoke-test.
- [ ] Повторить установочный прогон release-сборки на реальном Android-устройстве перед отправкой.
- [ ] Проверить: 1–10 скриншотов, PNG/JPG, до 3 МБ, 9:16, максимум 2160×3840.
- [x] Экспортировать иконку 512×512 PNG весом до 3 МБ.
- [ ] Разместить политику конфиденциальности на публичном HTTPS-адресе.
- [ ] Загрузить AAB/APK и, для AAB, отдельно добавить подписи в RuStore Консоль.
- [ ] Заполнить анкету возрастного рейтинга (ожидаемо 0+), отсутствие рекламы/покупок/сбора данных.
- [ ] Отправить на модерацию только после заполнения владельцем юридических и контактных данных.

Актуальные требования проверены 14.08.2026 по официальной документации RuStore.
