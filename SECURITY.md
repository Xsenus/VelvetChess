# Безопасность

Если вы обнаружили уязвимость в «Шахматах Velvet», не публикуйте её в открытом issue. Отправьте описание и шаги воспроизведения на `ilel@list.ru`.

Версия 1.0 работает офлайн и не принимает сетевые подключения. Для будущего онлайн-режима правила ответственного раскрытия будут дополнены до запуска серверной части.
