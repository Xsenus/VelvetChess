# Ручной QA-чек-лист

- Новая партия запускается на каждом уровне сложности.
- ИИ отвечает и интерфейс не блокируется дольше лимита уровня.
- Недопустимый ход не меняет позицию.
- Проверены рокировки в обе стороны, взятие на проходе и четыре превращения пешки.
- После шаха разрешены только выводящие из шаха ходы.
- Мат, пат и недостаток материала завершают игру корректно.
- Доска переворачивается без изменения позиции.
- Все 50 задач открываются; неверный ход не портит позицию; решение завершается.
- Интерфейс проверен на малом телефоне, планшете, светлой/тёмной системной теме и повороте экрана.
- Проверены холодный старт, сворачивание/возврат и отсутствие сети.
- Release APK/AAB установлен поверх предыдущей версии с тем же ключом.
